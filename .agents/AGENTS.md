# Project Rules

## NixOS & Package Querying (`mcp-nixos`)

- Always use `mcp-nixos` (installed at `/run/current-system/sw/bin/mcp-nixos` or accessible via `mcp-nixos` / `uvx mcp-nixos`) for querying and searching Nix ecosystem info.
- Refer to [MCP-NixOS Usage Documentation](https://mcp-nixos.io/usage) for tool actions, options, and query schemas.
- Use `mcp-nixos` when looking up NixOS packages, NixOS options, Home Manager options, nix-darwin settings, Flakes/FlakeHub, Nixvim/NVF options, Noogle function signatures, and NixOS Wiki docs.
